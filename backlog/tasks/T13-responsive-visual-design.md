# T13 - Responsive Visual Design

## Goal

Make the app polished, responsive, and pleasant to review.

## Files To Create Or Edit

- `src/app/App.css`
- Component CSS files if the project uses component-level styles

## Steps

1. Match the exam layout: search/results area, central image area, and recent searches area.
2. Make the layout work on mobile and desktop.
3. Give image containers and result tiles stable dimensions to prevent layout shifts.
4. Style loading, empty, error, selected, disabled, hover, and focus states.
5. Ensure long result titles do not overflow their containers.
6. Keep color, spacing, and typography consistent.
7. Check that the app still works after styling.

## Done Checks

- UI is usable on narrow and wide screens.
- Text does not overlap or overflow buttons/cards.
- Buttons and interactive items feel clearly clickable.
- Layout does not jump when images load.

## Best Practice Notes

- Use CSS grid and flexbox.
- Prefer stable aspect ratios for images.
- Keep animations subtle and fast.
